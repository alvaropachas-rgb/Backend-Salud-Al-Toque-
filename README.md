# 🩺 Salud al Toque

**Salud al Toque** es una aplicación web que permite a los usuarios encontrar y comparar profesionales de la salud según su especialidad, precio, ubicación, disponibilidad y calificación.

El objetivo del proyecto es facilitar el acceso a atención médica, odontológica y psicológica particular, permitiendo que los pacientes encuentren profesionales que se adapten mejor a sus necesidades.

## 🚀 Funcionalidades principales

- Registro e inicio de sesión.
- Perfil para pacientes y profesionales de la salud.
- Búsqueda de profesionales por especialidad.
- Filtros por ubicación, precio, disponibilidad y calificación.
- Visualización del perfil del profesional.
- Visualización de servicios y consultorios.
- Gestión de horarios disponibles.
- Solicitud y gestión de citas.
- Reseñas de pacientes.
- Profesionales favoritos.

## 📌 MVP

El MVP del proyecto incluye:

- Registro e inicio de sesión.
- Creación de perfil profesional.
- Búsqueda y filtrado de profesionales.
- Solicitud y gestión básica de citas.

## 🗃️ Entidades principales

El sistema considera las siguientes entidades:

`User`, `Patient`, `Professional`, `Specialty`, `Service`, `Office`, `Availability`, `Appointment`, `Review` y `Favorite`.

Estas entidades permiten administrar usuarios, profesionales, especialidades, servicios, consultorios, horarios disponibles, citas y reseñas.

## 🛠️ Aspectos técnicos

El proyecto será desarrollado como una aplicación web que incluye:

- Backend.
- Frontend.
- Base de datos relacional.
- API REST.
- Integración con Google Maps para mostrar consultorios.
- Sistema de notificaciones y recordatorios.
- Pruebas del sistema.

Uno de los principales retos del proyecto es manejar correctamente la disponibilidad de horarios y evitar que dos pacientes puedan reservar una misma hora.
